# Contributing to Gadd Kaam – SkillSwap Pakistan

Thank you for your interest in contributing to **Gadd Kaam – SkillSwap Pakistan**, a Final Year Project developed at the Department of Software Engineering, University of Sindh, Jamshoro.

---

## Code of Conduct
We are committed to maintaining a welcoming, inclusive, and professional environment. All contributors are expected to uphold standards of mutual respect and integrity.

## Development Workflow
1. **Fork or Clone the Repository:**
   ```bash
   git clone https://github.com/farmanullah1/Gadd-Kaam-SkillSwap-Pakistan-Final-Year-Project.git
   ```
2. **Create a Feature Branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Coding Standards:**
   - Use clean, modular, and well-commented code.
   - Follow semantic naming conventions for React components and Express routes.
   - Never commit sensitive files, credentials, or `.env` files.
   - Keep styling consistent with the existing Tailwind CSS design tokens.
4. **Testing:**
   - Verify changes locally before submitting. Run backend checks (`node db_check.js`) and ensure frontend builds cleanly without warnings.
5. **Commit Message Format:**
   - Use clear prefixes such as `feat:`, `fix:`, `refactor:`, `docs:`, `style:`.
6. **Submit a Pull Request:**
   - Describe what problem your PR solves and reference any relevant issues.
